2. Какие данные могут обрабатываться

В зависимости от используемых функций Сервис может обрабатывать следующие категории данных:

  • данные учётной записи: адрес электронной почты, идентификатор пользователя и сведения, необходимые для входа;
  • данные профиля, которые пользователь добровольно указывает в Сервисе;
  • данные о действиях внутри Сервиса, например поисковые запросы, избранные элементы и настройки;
  • технические данные: тип браузера и устройства, язык, примерное время запросов, журналы ошибок и сведения, необходимые для защиты Сервиса;
  • данные YouTube, если пользователь самостоятельно подключит свой аккаунт Google и предоставит соответствующие разрешения.

Сервис не должен запрашивать пароль от аккаунта Google или YouTube. Авторизация через Google выполняется на стороне Google.

3. Подключение Google и YouTube

В будущем Сервис может позволить пользователю подключать YouTube-канал через Google OAuth. При подключении Google покажет перечень разрешений, которые запрашивает Сервис. Доступ предоставляется только после согласия пользователя.

В зависимости от выданных разрешений Сервис может получать данные канала и аналитические показатели YouTube, необходимые для отображения статистики и работы функций FORESCAN. Объём доступных данных определяется разрешениями Google и YouTube API.

Данные, полученные через API Google, используются только для функций, описанных в Сервисе и в предоставленном пользователем согласии. Сервис не продаёт данные Google/YouTube и не использует их для показа рекламы.

Пользователь может отозвать доступ Сервиса в настройках своего аккаунта Google. После отзыва некоторые функции FORESCAN могут перестать работать. Дополнительные сведения об использовании данных Google API должны соответствовать требованиям Google API Services User Data Policy, включая требования Limited Use.

Примечание: этот раздел описывает планируемую интеграцию. До её запуска оператор должен проверить, какие именно данные сохраняются, где они хранятся, как долго используются и как пользователь может удалить их.

4. Для чего используются данные

Данные могут использоваться для:

  • создания и защиты учётной записи;
  • предоставления функций поиска, анализа и отслеживания трендов;
  • отображения статистики подключённого YouTube-канала;
  • сохранения пользовательских настроек и избранного;
  • диагностики ошибок, предотвращения злоупотреблений и обеспечения безопасности;
  • ответов на обращения пользователей и выполнения требований применимого законодательства.

5. Правовые основания обработки

Обработка осуществляется на основаниях, применимых к конкретной ситуации: согласие пользователя, необходимость предоставления запрошенной функции, исполнение обязанностей оператора по закону и иные законные основания, если они применимы.

6. Хранение и защита данных

Оператор применяет разумные технические и организационные меры для защиты данных от неправомерного доступа, изменения, раскрытия или уничтожения.

Данные хранятся не дольше, чем это необходимо для целей обработки, если более длительный срок не требуется законом. Конкретные сроки хранения и используемые инфраструктурные сервисы должны быть указаны оператором после окончательного выбора и настройки технической архитектуры FORESCAN.

Секреты OAuth, пароли и токены доступа не должны размещаться в открытом клиентском коде или публичном репозитории.

7. Передача данных третьим лицам

Данные могут обрабатываться поставщиками инфраструктуры и сервисов, которые необходимы для работы FORESCAN (например, хостинг, база данных и сервис авторизации), а также передаваться государственным органам, если такая передача требуется применимым законодательством.

Перед публикацией этой политики оператор должен перечислить фактически используемых поставщиков, указать их роли и проверить условия международной передачи данных, если она происходит.

8. Файлы cookie и технические технологии

Сервис может использовать cookie, локальное хранилище браузера и аналогичные технологии для поддержания сессии, сохранения настроек и обеспечения безопасности. Если используются аналитические или рекламные технологии, их назначение и способы управления ими должны быть отдельно описаны здесь.

9. Права пользователя

В пределах, предусмотренных применимым законодательством, пользователь может обратиться к оператору, чтобы запросить сведения об обработке своих данных, исправить неточные данные, отозвать согласие или потребовать удаления данных, если для их дальнейшего хранения нет законного основания.

10. Данные несовершеннолетних

Сервис не предназначен для сбора данных детей с нарушением применимого законодательства. Если оператору станет известно, что данные были предоставлены с нарушением установленных законом требований к возрасту или согласию законного представителя, оператор рассмотрит обращение и примет необходимые меры.

11. Изменения политики

Оператор может обновлять эту Политику при изменении функций Сервиса, способов обработки данных или требований законодательства. Актуальная версия публикуется на этой странице с указанием даты последнего обновления.

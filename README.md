# StandLink 0.1.0

Мобильный Firebase-проект социальной сети для Standoff 2.

## Структура
- `index.html` — точка входа.
- `styles.css` — интерфейс и анимации.
- `app.js` — Firebase Auth/Realtime Database и логика приложения.

## Что уже есть
- Google-only авторизация.
- Onboarding с уникальным username, ID Standoff 2 и описанием.
- Firebase-профиль без демо-пользователей.
- Друзья: поиск по username, заявки, принятие.
- Чаты: реальные сообщения между друзьями в Realtime Database.
- Сообщество — пустое состояние до реализации.
- Профиль и редактирование.
- Настройки темы, акцентного цвета и языка.
- Скрытая проверка разработчика после 24 нажатий на StandLink.
- Версия проекта: 0.1.0.

Firebase Web config уже находится в `app.js` согласно предоставленной конфигурации проекта.

Важно: правила Firebase Realtime Database должны разрешать нужные операции. Этот архив не выполняет автоматическое развёртывание правил в Firebase.

## StandLink Designer
`designer.html` — визуальный редактор интерфейса для телефона. Элементы можно добавлять, перетаскивать пальцем, менять размер/координаты/текст и экспортировать в `standlink-layout.json`. Открывается из Настроек → StandLink Designer.

## Обновлённый профиль
Профиль переработан по визуальному референсу: тёмный Standoff 2 стиль, фирменный знак StandLink, обложка, аватар, статистика, кнопки, вкладки и нижняя навигация. Элементы интерфейса остаются HTML-кнопками, поэтому их можно нажимать и подключать к Firebase/другим действиям.

## Profile share
Кнопка «Поделиться» теперь открывает выбор друзей из Firebase и отправляет профиль как карточку прямо в их личные чаты. Логотип StandLink использует прозрачный PNG.


## Profile reference lock
Профиль v0.1.0 сверстан по предоставленному мобильному референсу. Обычные аккаунты получают нейтральный фон и пустой круг аватара; фон, специальная аватарка и галочка выдаются только аккаунту разработчика. Статус разработчика активируется 26 нажатиями на логотип StandLink и вводом секретного кода; статус сохраняется в Firebase в `users/{uid}.isDeveloper`.

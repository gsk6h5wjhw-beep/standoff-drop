# StandLink 0.1.0

Первая рабочая версия социальной сети StandLink.

## Запуск

Это обычный статический сайт: `index.html` можно разместить в GitHub и подключить репозиторий к Vercel.

## Firebase

В `firebase-config.js` уже добавлен предоставленный Firebase Web Config.

Перед первым входом в Firebase Console нужно включить:
- Authentication → Sign-in method → Google
- Realtime Database

После изменения правил базы импортируй содержимое `firebase-rules.json` в Realtime Database Rules.

## Что уже есть

- Google-вход
- первичная настройка профиля
- уникальный username
- игровой ID Standoff 2
- описание и аватар-эмодзи
- светлая / тёмная / авто тема
- 6 акцентных цветов
- русский / английский
- главная лента с демонстрационными постами
- друзья и поиск по username
- заявки в друзья
- чаты-заготовка
- сообщества
- профиль
- настройки
- выход из аккаунта
- версия 0.1.0
- скрытая панель разработчика после 24 нажатий на StandLink

## Важно

Медиафайлы, реальные сообщения, приглашения в Standoff 2, push-уведомления, посты и полноценная система друзей пока являются следующим этапом. UI уже подготовлен под них.
